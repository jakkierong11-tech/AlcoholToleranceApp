### 关键教训
1. **`openclaw gateway restart` 会中断当前回复** → 以后用 cron 延迟 10 秒重启避免断话
2. **`models.providers` 不可通过 patch 批量替换已有模型** → 安全机制拒删，用 Node 直写 JSON
3. **主 Bot account 配置时注意不覆盖** → 配子 agent 时覆盖了 main token，需单独补回
4. **KIMI 2.6 不稳定** → 用户要求换成 KIMI 2.5
5. **moonshot API Key 在清理模型时被误删** → 已恢复
