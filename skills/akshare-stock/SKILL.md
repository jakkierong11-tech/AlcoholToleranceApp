# A 股量化数据 Skill - AkShare

## 功能
- 📈 实时行情查询
- 📊 历史 K 线（日/周/月）
- 💰 财务数据
- 🏢 板块/行业分析
- 💸 资金流向
- 🐉 龙虎榜
- 📰 新股/IPO
- 📉 融资融券

## 使用方法

```powershell
# 在 OpenClaw 中直接对我说：
- "查询贵州茅台的实时行情"
- "显示平安银行最近 30 天的 K 线"
- "看看半导体板块的股票有哪些"
- "查询今天的龙虎榜"
```
